# aravbazar.github.io

Portfolio site and live demos by Arav Bazar: AI voice agents, chat agents, automations and custom software for agencies.

Live: https://aravbazar.github.io

| Demo | What it shows |
| --- | --- |
| [/receptionist](https://aravbazar.github.io/receptionist/) | AI phone receptionist for a med spa with booking rules enforced in code |
| [/roofing](https://aravbazar.github.io/roofing/) | Website chat agent that answers from a knowledge base with sources and books inspections |
| [/speed-to-lead](https://aravbazar.github.io/speed-to-lead/) | Lead pipeline that cleans, dedupes, scores and texts every lead within a minute |
| [/crm](https://aravbazar.github.io/crm/) | Custom CRM pipeline with stage automations |
| [/text-back](https://aravbazar.github.io/text-back/) | Missed-call text-back and review requests |
| [/agent-ops](https://aravbazar.github.io/agent-ops/) | Monitoring for every AI agent an agency runs |

All businesses in the demos are fictional and all data is sample data. Plain HTML, CSS and JavaScript with no build step.
